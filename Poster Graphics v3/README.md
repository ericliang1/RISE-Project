# Methane Poster Graphics — v3 (super-emitter benchmark)

The complete `Poster Graphics v2` set rebuilt on the **super-emitter
benchmark** (branch `super-emitter`, frozen data in
`/projectnb/rise-tower/eric1/csr-data-se48`):

- population q ~ LogU(**100, 500**) kg/h (all super-emitters), **4–8** masts;
- final method **`ens` = three physics channels** (mean evidence z, wind
  spread, mean log b over the same K = 8 wind draws) — the residual
  "fit-quality" map was **dropped** from the method, and the evidence
  channel uses the **asinh transform** (no hard clip);
- all networks trained with the head-warmup recipe (`PW_HEAD_WARMUP=100`);
- the physics-only oracle uses K_TEACHER = 8, the same marginalization
  budget as the maps.

Styling continues the v1/v2 house style: orange = without physics maps,
blue = with physics maps, dashed ink = the 50 m facility-scale reference,
model palette DeepSets **blue** `#2a78d6` / GNN **red** `#c94040` / Set
Transformer **green** `#1baf7a` (CVD-checked; every curve direct-labelled).

## Where the numbers come from

Nothing is transcribed by hand.  The script reads the frozen files under
`/projectnb/rise-tower/eric1/csr-data-se48`:

- conformal audits `pw_audit_pw_noisy_{nomaps,ens}[_gnn|_st]_seed{1,2,3}_noisy.npz`
  (region sizes → equivalent-area radii; `covered`; packed region masks) —
  on this benchmark **every** audit stores coverage, so Fig. 07 shows all
  three seeds for every model (the v2 DeepSets-seed-2/3 caveat is gone);
- physics feature maps `ch4tu_test_maps_ens.npz`
  (channels: mean evidence z̄ (asinh), wind spread 3·std z, mean log b);
- test scenarios `ch4t_test.npz` and the exact known-wind posterior
  `ch4t_test_posterior.npz`;
- `results/se48_table_deltas_ci.json` for the paired-bootstrap CIs
  (Fig. 06) — the same file behind `results_package/tables_se48.pdf`.

### Example-scenario rules (stated, as in v1/v2)

**Fig. 01 / 01.5** (typical example): among scenarios with exactly
**6 masts** (the midpoint of 4–8; v2 used 8 = the midpoint of 4–12) whose
baseline and physics regions both cover the source **and whose known-wind
exact posterior is concentrated** (max-cell mass ≥ 0.9), the one jointly
closest (log scale) to the subgroup's median baseline and physics radii →
test index **312** (6 masts, 126 kg h⁻¹, posterior max-cell mass 100%).
The concentration criterion is **new in v3** and disclosed here: on the
super-emitter population the known-wind posterior collapses to
essentially one cell for the typical scenario (52% of all scenarios and
57% of the 6-mast subgroup exceed 0.9 max-cell mass; median max-cell mass
0.975) but a minority stay diffuse, and panel E should show the typical
collapsed case, not an outlier.

**Fig. 03** (deliberately favourable case, labelled as such): among
8-mast scenarios where **all six** seed-1 regions cover the source, the
one **maximizing the baseline-to-physics contrast** (sum over models of
log baseline radius minus log physics radius) → test index **1542**,
283 kg h⁻¹, giving 73/49/47 m without maps vs 22/24/20 m with.  Do not
quote its numbers as typical — the medians are below and in Figs. 04–05.

### Key derived numbers (medians, three seeds pooled)

- with-maps all scenarios: DeepSets **74.3 m**, GNN **61.9 m**,
  Set Transformer **64.3 m**
- with-maps 8-mast subgroup: **66.0 / 55.2 / 58.1 m** (79–82% of the
  all-scenario area)
- without-maps all scenarios: **98.8 / 68.7 / 73.8 m**
- seed-1 within-50 m share (Fig. 04): with maps 24% averaged over the
  three models, without maps 5%

## The UMAP figure (Fig. 02), honestly stated

Same construction as v2: UMAP (`n_neighbors=30, min_dist=0.15,
random_state=1`) of the per-scenario **source-evidence map** (first `ens`
channel), z-scored per scenario, 50 PCA components first.  Panels A/B: the
embedding axes recover the site's east–west and north–south axes — the
physics input encodes the source location before any network is trained.
Panel C: region size is *locally structured* (Spearman rank correlation
**0.25** between a scenario's log-radius and its 15 nearest neighbours'
mean, p ≈ 3×10⁻³⁰ — weaker than the full-population 0.33, quoted on the
figure).  Wind direction remains unclaimed.

## The wind-ensemble figure (Fig. 01.5)

The eight per-draw evidence maps are **regenerated, not schematic**: the
script imports the branch's `src/methane_t_uncertain.py` (asinh zmap) and
replays `stage_gen`'s exact construction (`perturb_wind` with RNG streams
`[root_entropy, 92, split_tag, i, k]`, `root_entropy = 20260717`), then
verifies the recomputed mean against the stored `ens` channel — max abs
difference **5×10⁻⁷** (float32 rounding).  Panel C overlays the ens
seed-1 conformal region (73 m) for the same scenario as Fig. 01.

## Caveats to keep on the poster

- Figs. 03/04 use the prespecified seed-1 run (same convention as
  Table I's paired effects); Fig. 05 pools the three seeds.
- Fig. 06: on this benchmark **every** CI excludes zero (in v2 the GNN's
  radius CI crossed zero; here it is −5.2 m [−6.4, −4.2]).
- The benchmark's mast range was iterated (6–12 → 2–8 → 4–8) before
  freezing; the paper must disclose that — see GATES.md.  These figures
  show only the frozen 4–8 population.
- Fig. 01 panel E: the exact known-wind posterior is drawn as geometry
  because for the chosen (typical) scenario it is a genuine near-delta;
  the measured max-cell share is printed on the panel and the selection
  criterion above keeps that panel honest.

## Regeneration

```bash
source scripts/env.sh
python "Poster Graphics v3/generate_poster_graphics_v3.py"
```

Requires `umap-learn` in addition to the env's numpy/matplotlib/sklearn
(installed in the spring-2026 env with `pip install --user umap-learn`).
